# Banking Management System

## About the Project
A console-based Banking Management System developed using C++ and Object-Oriented Programming concepts.

## Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling

## Features
- Account creation
- Display account details
- Deposit money
- Withdraw money
- Balance enquiry
